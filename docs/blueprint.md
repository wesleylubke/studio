# **App Name**: GanttFlow

## Core Features:

- Project Creation & Management: Users can create new projects, define project names, and set initial project parameters.
- Task Definition: Add, edit, and delete individual tasks within a project, including specifying task names, descriptions, start dates, and end dates.
- Interactive Gantt Chart: Visualize project tasks and their timelines on an interactive Gantt chart, allowing users to intuitively see project schedules.
- Progress Tracking: Update the completion status and progress percentage for each task, with visual feedback reflected on the Gantt chart.
- AI Task Assistant Tool: An AI-powered tool that suggests a breakdown of common tasks for new projects based on the project's description, helping to kickstart planning.

## Style Guidelines:

- Background color: Deep, desaturated navy (#141820) to create a focused and professional dark mode environment.
- Primary action color: A vibrant, clear blue (#5091F8) for interactive elements like buttons and active states, ensuring good visibility against the dark background.
- Accent color: A bright, airy cyan (#B7EEFC) to provide highlights, callouts, and delineate progress within the Gantt chart, offering a strong visual contrast.
- Secondary color: A light, neutral gray (#BFBFBF) for text and secondary interface elements, ensuring readability and supporting the professional aesthetic.
- All text uses 'Inter' (sans-serif) for its modern, clear, and objective appearance, optimizing readability for detailed project information and timeline views.
- Utilize a suite of simple, clean line icons that convey professionalism and clarity, ensuring they integrate seamlessly with the minimal design while effectively communicating actions and status.
- The layout is clean and structured, with a primary focus on the interactive Gantt chart. Information is presented logically, minimizing clutter to facilitate efficient project overview and management.
